# CloudOps Enterprise Platform

## Project Overview

An AWS-based CloudOps and DevOps platform integrating infrastructure as code, serverless computing, containerization, Kubernetes, CI/CD, monitoring, databases, event-driven processing, and ML data processing.

## Architecture

→ Lambda
→ DynamoDB

## Event-Driven Architecture

SQS messages trigger the Lambda function automatically.

Lambda processes the event and stores the resulting record in DynamoDB.

## ML/Data Pipeline

A sample CSV dataset is stored in Amazon S3 and processed using a Python/scikit-learn training script.

The pipeline generates model evaluation metrics.
